# aimlapi-async-jobs

Video and music jobs and background responses: submit, poll, download. Speech is in [aimlapi-speech](../aimlapi-speech/README.md).

## Install

```bash
gh skill install aimlapi/skills aimlapi-async-jobs
```

Or install every skill: see the [root README](../../README.md#install).

## What it covers

- Submit, poll and download for video, music and background responses
- A standard-library script with sandbox mode, deadlines and resumable polling

The agent reads [SKILL.md](SKILL.md).

## Requirements

`AIMLAPI_API_KEY`; `python3` for the script.
